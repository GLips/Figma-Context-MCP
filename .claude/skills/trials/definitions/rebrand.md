## Brief

Design a pricing page for a note-taking app called Marginalia. Three tiers — Free, Pro ($8/mo), Team ($15/user/mo) — with Pro highlighted. Each tier lists four features and has a call-to-action button. Desktop width, light theme, blue accent, a geometric sans. Build it in the Figma file I have open, on a new page named "{page}".

## Follow-up

Marginalia got acquired. Rebrand the page you just built in place: the product is now called Ledgerline, the accent is a deep green, the type is a humanist serif for headings and a system sans for body, and corners go from rounded to square. Same page, same structure — nothing else changes.
