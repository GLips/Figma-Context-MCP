## Brief

Design a settings screen for a desktop email client (1200×800). Left column lists sections: Account, Notifications, Appearance, Shortcuts, Privacy. The right side shows Notifications selected: grouped rows, each a label with a one-line description and a toggle, some with a dropdown instead. A footer with Cancel and Save. Neutral, quiet, light theme. Build it in the Figma file I have open, on a new page named "{page}".

## Rubric

- Rows are a repeated component in spirit: identical heights, alignment, and control placement.
- Toggles have on and off states; the dropdown looks native, not a rectangle with a caret.
- Section grouping is visible through spacing and headers, not only lines.
- The selected nav item is obvious and the rest are calm.
